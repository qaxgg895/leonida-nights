Leonida Nights is an original open-world crime game set in the fictional city of Vice Shores: drive and walk a low-poly 3D sunset city rendered by a hand-written Canvas 2D engine (no 3D library, no network at runtime), steal cars, dodge traffic and pedestrians, build a wanted level and lose the cops, fight rival guards, and run four story missions — meet the fixer, steal the getaway car, lose the cops, deliver the package — with a HUD, minimap, clock, generated WebAudio sound, and localStorage saves. Nothing in it comes from Rockstar: the city, names, story, art and sound are all original.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
# then open out/game/index.html, or serve the game directly: npx serve game
```

Play it in desktop Chrome: WASD to walk/drive, E to steal or enter a car, click to punch or shoot, Space for the handbrake, P to pause, M to mute. Screenshot scenes: `?shot=start`, `?shot=play`, `?shot=end`, `?shot=night` (add `&seed=1` for reproducible frames).
